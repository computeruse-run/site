What is Computer Use?

The first AI capability that actually uses the computer.

Computer Use is a class of AI agent capability where a large language model controls a real browser or desktop — clicking, typing, scrolling, reading screenshots — to complete tasks end-to-end. Anthropic released the first widely-used Computer Use API in October 2024; OpenAI shipped Operator in early 2025; Google added Gemini agent capabilities in 2026.

Computer Use Cloud runs all three on managed sandboxes behind a single API, so you don't host browsers, you don't pay for idle time, and you can swap providers with one line.

One API, three models

Swap Claude, OpenAI, and Gemini with one line.

We wrap Anthropic's Computer Use Beta, OpenAI's computer-use-preview, and Gemini's agent endpoint in a single surface. Same Sandbox object, same tools, same screenshot loop. Switch providers per task.

  • ▸Bring your own API key, or use our pooled credits.
  • ▸Built-in screenshot, DOM, and accessibility-tree capture.
  • ▸Residential proxy and captcha solving on by default.
  • ▸Live view URL — embed the running session in your app.
# Anthropic Computer Use, pre-configured.
from computeruse import Sandbox

with Sandbox.claude(model="claude-sonnet-4-6") as sb:
    sb.goto("https://www.google.com/flights")
    result = sb.agent.run(
        "Find the cheapest direct flight"
        " SFO → LIS next Tuesday. Return the airline,"
        " price, and departure time."
    )

    print(result.value)
    print(f"cost: ${result.usage.usd}")
    print(f"active: {result.usage.active_seconds}s")

Frequently asked

What developers ask before signing up.

What is Computer Use? +
A class of AI agent capability where a large language model controls a real computer — clicking, typing, scrolling, reading screenshots — to complete tasks on a real browser or desktop. Anthropic released the first widely-used Computer Use API in October 2024; OpenAI shipped Operator in early 2025; Google added Gemini agent capabilities in 2026.
How is Computer Use Cloud different from Browserbase? +
Three differences. First, price — we charge per active second, not per browser-hour, so idle is free. For typical agent workloads that's 60% cheaper. Second, three models behind one API — Claude, OpenAI, Gemini, swappable with one line. Third, faster cold starts (2 seconds vs 3-5).
Does it work with Claude Computer Use Beta? +
Yes. The Claude provider is a managed wrapper around the official Anthropic Computer Use Beta API. You bring your own Anthropic API key or use our pooled credits; we run the sandbox, capture screenshots, return the accessibility tree, and forward tool calls back to the model.
Does it work with OpenAI Operator? +
Yes. The OpenAI provider wraps the Operator API (the computer-use-preview model). Same one-line swap from Claude — Sandbox.openai() instead of Sandbox.claude() — and the rest of your agent code is unchanged.
Can I self-host? +
Yes. The runtime is open source under Apache 2.0 — clone it, run it on your own infrastructure, point your SDK at the self-hosted endpoint. The cloud is for teams who would rather pay per active second than maintain a sandbox fleet.
How do I migrate from Browserbase? +
Most Browserbase agent code is a Playwright session wrapped in their SDK. Computer Use Cloud exposes the same Playwright CDP endpoint plus higher-level Sandbox.claude() / Sandbox.openai() helpers. Swap the connection string and one import; the rest of your agent code keeps working. Full migration guide →
Is there a free tier? +
Yes. 10 active hours per month, free forever, no credit card. After that, Pro is $20/month for 100 active hours plus $0.05 per additional active hour.
What runs inside the sandbox? +
A pre-configured Linux container with Chromium, common fonts and codecs, residential proxy by default, captcha solver, accessibility-tree extractor, and the screenshot pipeline tuned for vision LLMs. You get a Playwright CDP endpoint plus the high-level Sandbox helpers.
