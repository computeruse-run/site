Frequently asked

What developers ask before they sign up.

What is the relationship between Computer Use Cloud and Anthropic Computer Use? +
Anthropic provides the Computer Use model — the brain. Computer Use Cloud provides the browser it acts on — the body. You keep your Anthropic API key and your existing tool schema; we replace the self-hosted Docker container that Anthropic's reference implementation expects you to build and operate yourself.
I already use the Browser Use SDK. How much code do I have to change? +
One line. Browser Use SDK reads a CDP endpoint URL from configuration; change it to wss://connect.computeruse.run and the rest of your agent script keeps working. No SDK swap, no rewrite.
Where exactly are you cheaper than Browserbase? +
Browserbase bills per browser-hour — the meter runs while the model is thinking. We bill per active second; model-thinking idle is free. On a standard agent task (10 min browser + 30 LLM steps + 1 CAPTCHA), the bill is about $0.10 on Browserbase versus $0.01 on us. For pure CDP scraping with no model loop, the gap shrinks to roughly 15%.
Is my data secure? Can I self-host? +
Yes to both. Sandboxes are isolated per tenant and per session; nothing is shared across customers. The runtime is open source under Apache 2.0 — Team plan customers get a Docker self-host license, run the same sandbox image inside their own VPC, and point the SDK at their endpoint. Data never leaves the customer's infrastructure.
How are CAPTCHA, residential IP, and concurrency limits handled? +
CAPTCHA solving and residential proxy are included by default on every plan, not metered as add-ons. Concurrency: Free 5 sandboxes simultaneously, Pro 25, Team unlimited within fair use. Residential IP rotates per session by default; sticky IP available on request.
What LLMs are supported? Is it Claude-only? +
Not Claude-only. Three first-class providers — Anthropic Claude Computer Use, OpenAI Operator (computer-use-preview), and Google Gemini agent. Any LLM with vision input and tool calling can drive the browser via the unified Sandbox API. Browser Use SDK users get all the LLMs Browser Use already supports (15+ providers).
Can I replay a failed run? Is there session recording? +
Yes. Every session has a live view URL while running and a recorded video plus transcript afterward (Pro 7-day retention, Team 30-day). The full action timeline and model decisions download as JSON for debugging or training data.
What's in the free tier? Is a credit card required? +
100 active hours per month, free forever, no credit card. Enough to run a hackathon over a weekend or a side project for the month. After 100 hours the sandbox stops; no surprise overage on Free.
