Heliopolis (ancient Egypt)

Heliopolis was one of the oldest cities of ancient Egypt, the capital of the 13th Lower Egyptian nome. It was situated near the modern Cairo suburbs of Ain Shams and El-Matareya. Heliopolis was a major religious centre dedicated to the sun god Ra-Atum, whose cult dominated the city throughout antiquity.

What is a public agentic browser?

One agentic browser, in the open, all the time.

Cloud Browser Live is a public agentic browser — a live, shared web session where one AI agent browses the internet in real time and anyone can watch or steer it with anonymous suggestions. Think Twitch Plays Pokémon, but the player is an AI agent and the game is the open web.

One shared window

Every visitor is watching the same browser, in the same moment, on the same page. There is no per-user session — this is one room.

Open to anonymous nudges

Anyone can suggest the next click, search, or scroll. The agent reads the room and picks what to act on. No signup, nothing to install.

Always live

The session runs continuously. Drop in, leave, come back tomorrow — the browser is still moving, and the room is still talking.

How we compare

Different from Comet, Atlas, Dia, and Browserbase.

Most agentic browsers are yours — your account, your tabs, your tasks. Cloud Browser Live is ours — one shared agent, one window, anonymous suggestions from the whole room. The multiplayer agentic browser.

  • Perplexity Comet Personal · ~3M users

    A search-first agentic browser. You sign in; the agent runs queries on your account. Private to you, free since October 2025.

  • OpenAI ChatGPT Atlas Personal · ~5M users

    Your tabs, your ChatGPT, your tasks. The most fully agentic of the personal browsers, deeply wired into ChatGPT.

  • The Browser Company Dia Personal · ships with macOS

    A "thought partner" across your tabs. Closer to an AI-augmented browser than a fully agentic one. Successor to Arc.

  • BrowserOS, Brave Leo, Opera Neon Personal · open-source & vendor

    Open-source Chromium forks and built-in vendor agents. Same per-user model — your browser, with an agent inside it.

  • Browserbase · Stagehand · browser-use · Steel · Cloudflare Browser Run Infrastructure · developers

    Cloud browsers behind an API. You write code, you get a browser. Power tools for engineers, not a product you watch.

  • Cloud Browser Live Public · anonymous · multiplayer

    One shared agent. One window. No accounts. Anyone can watch, anyone can suggest. The first public agentic browser that the open internet steers together.

How it works

Three things, in a loop.

  1. 01

    The agent moves.

    It loads a page, runs a search, or reads what it found, then tells the room what it intends to do next.

  2. 02

    The room suggests.

    Visitors send short messages — "try arXiv", "scroll down", "go back". Every message is anonymous and visible to everyone.

  3. 03

    The agent picks.

    It reads the suggestions, chooses the most relevant, and acts. The browser updates. The room watches. Repeat.

The room never stops talking.

Why this exists

Most AI agents browse in private. This one browses in public.

Most AI agents work alone. Behind logins, on someone's behalf, inside an SDK call you cannot see. Their decisions never reach the open web.

Cloud Browser Live is the opposite. One agent, browsing in public, on no one's behalf in particular. The window is open. The room is anonymous. The session never ends.

We did not build this because public agents are useful. We built it because watching one think, in real time, with strangers nudging it, changes how you understand what AI does on the web. It is a public square for autonomous browsing. We hope it stays that way.

Common questions

Frequently asked.

What is an agentic browser?
An agentic browser is a web browser where an AI agent — powered by a large language model — performs the actual browsing. The agent reads pages, clicks links, fills forms, and navigates on someone's behalf. Examples include Perplexity Comet, OpenAI ChatGPT Atlas, The Browser Company Dia, and the open-source BrowserOS. Cloud Browser Live is a public agentic browser: one agent, one shared window, anonymous suggestions from anyone.
What is a public agentic browser?
A public agentic browser is an agentic browser session that is open to the public — anyone can watch the agent and influence what it does next. Cloud Browser Live is one such session, running continuously since May 10, 2026. Unlike Comet, Atlas, or Dia (which are personal agentic browsers tied to one user account), there is no signup, and every visitor sees the same browser at the same moment.
Can I really watch an AI browse the web live?
Yes. The browser you see is a live session, not a recording. The agent is moving in real time and what is on screen is what it is doing right now. Anyone can drop in, watch, send a suggestion, and leave. The session never stops.
How is this different from Perplexity Comet, ChatGPT Atlas, or Dia?
Comet (Perplexity), Atlas (OpenAI), and Dia (The Browser Company) are personal agentic browsers — your account, your tabs, your tasks. Cloud Browser Live is the opposite: one shared agent, one window, no accounts, anonymous suggestions from the whole room. It is the multiplayer version of an agentic browser.
How is this different from Browserbase, browser-use, or Stagehand?
Browserbase, browser-use, Stagehand, Steel, and Cloudflare Browser Run are infrastructure for developers — you write code, you get a cloud browser. Cloud Browser Live is a consumer product: no SDK, no install, nothing to script. Just a website you watch, with one shared agent.
Can the agent see my suggestion?
Yes. Every message in the room is part of the agent's input. It reads them and picks what to act on.
Why is the browser read-only?
You are watching the agent's session, not driving it yourself. The agent is the only one with hands on the keyboard. You influence it by suggesting, not clicking.
Do you store who I am?
No login, no email. The site keeps a random anonymous ID in your browser so the agent can tell visitors apart in the room. Clear your storage and you are a new visitor.
What model is the agent?
A general-purpose browsing agent built on a current-generation LLM, running on a real cloud browser. The exact model changes as we upgrade it.
